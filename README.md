# ファッションを学ぶ

参考にするYouTube動画を1本ずつ追加していく、個人用HTML教材。

## 開き方

`ファッションを学ぶ.html` をブラウザで開く。本文・模式図・具体例の切り替え・確認問題・学習ワークは外部通信なしで利用できる。YouTubeのリンクだけはオンラインで使う。

メモ・問題の回答・学習済みの状態・選んだ具体例をlocalStorageに保存する。ファイルを直接開いた場合の保存はブラウザに依存するため、同じブラウザと場所で使い、必要に応じて「記録を書き出す」でJSONの控えを保存する。別のブラウザや更新後のファイルでは「記録を読み込む」で戻せる。「このワークをMarkdownで保存」は読みやすいテキストの控え用で、記録の復元にはJSONを使う。

## 収録した教材

- 第1本：TAKATO / タカトの「【服の合わせ方】そんなものを信じているからダサい！？コレがおしゃれな合わせ方です。」
- 出典：https://www.youtube.com/watch?v=2wUwcKRwHfI
- 公開日：2023-11-25／確認日：2026-10-12
- 確認資料：YouTubeの日本語自動字幕全編と概要欄。写真・動画の転載なし。
- 要点、メイン・サブ属性、3つの具体例、外しの2例、実践ワーク、4問の確認問題、7語の用語説明。
- 本文では動画の主張と、教材独自の補足・ワークを明示する。図は字幕説明から作成した模式図で、動画のコーデ写真を再現したものではない。
- 自動字幕の「スラックス」と前後のアイテム説明が合わない箇所は、前後に沿って最初の例をジャケット・シャツ・デニム・革靴として整理。未確認の画面細部や別動画の内容は追加しない。

### 第2本：抜け感と外しを、調和で読み解く

- TAKATO / タカトの「【これを真似るだけ】コーデの『抜け感』から『外し』まで、言語化するとこの理論になる。理解すればおしゃれ確定。」
- 出典：https://www.youtube.com/watch?v=QXHeM6swt70
- 公開日：2025-03-21／確認日：2026-10-12／25分00秒。
- 日本語自動字幕全編・概要欄・公式チャプターを確認。図は字幕から作成した模式図。
- きれいめ・カジュアルの土台、抜け感の2例、外しの4例、後半のコーデ分析2例、見えている面積の応用を収録。
- 「調和・抜け感・外し」の比較表、分析手順、動画専用の実践ワーク、解説付き確認問題5問、用語6語を追加。
- 黒いデニムのフレア形状、後半のパンツの種類、ネクタイの着方の役割など、動画自身にも推測を含む箇所は断定を避けた。
- 第1本の本文データ・ID・回答の対応は維持。保存キーも変更せず、教材別にメモ・回答を保存する。

## 今後の追加・編集

1. 動画の本文を確認し、`lessons.json` に既存と同じ構造のレコードを追加する。
2. 既存の `id` は変更しない。新しい教材には別の固定IDと番号を使う。既存IDが学習記録のキーになる。
3. このリポジトリのフォルダで `python3 build.py` を実行する。
4. 生成された単体HTMLを開き、動画一覧・新しい本文・リンク・問題・記録の復元を確認する。

ファイルの役割：`lessons.json` は動画別の内容、`template.html` は画面構成、`style.css` は見た目、`app.js` は保存と操作、`build.py` は単体HTMLの生成。データはビルド時に埋め込むため、実行時にJSONをfetchしない。

動画ごとに、属性の説明図・補足・出典注記・ワークを指定できる。`extensions` は必要な動画にだけ追加する応用章で、本文の番号と目次は自動生成する。既存ワークのキー `scene / attributes / connections / experiment` は保存に使うため変更しない。

教材の追加後も、既存IDのメモと回答を引き継ぐ設計。問題の選択肢や意味を変更する場合は古い回答との対応を確認する。

## ローカル表示確認

必要な場合は、このリポジトリのフォルダで `python3 -m http.server 8766 --bind 127.0.0.1` を実行する。

`http://127.0.0.1:8766/ファッションを学ぶ.html` にアクセスする。サーバー経由とファイルを直接開く場合では保存領域が違うため、記録はJSONで持ち運ぶ。

### 2026-10-12 の確認結果（第1本作成時）

- JavaScriptの構文チェック、教材データの解答範囲、HTMLの重複ID・内部リンク・外部アセットなしを確認。
- ブラウザ（ローカルHTTP）で3つの具体例の切り替え、未回答／誤答／全問正解の表示を確認。
- メモ・回答・学習済み・選んだ具体例が再読み込み後に復元されることを確認。
- JSONとMarkdownの書き出し内容を読み、JSONを読み戻して表示が戻ることを確認。画面の動作確認用入力は空の初期状態に復元。
- 現在の1280px幅で、冒頭と具体例の図を視覚確認。横方向のはみ出しなし、ブラウザのエラーログなし。
- 一時コピーに2本目のレコードを追加し、既存IDを維持して両教材を生成できることを確認。
- ファイルURLをアプリ内ブラウザで開く操作は、同ブラウザのURL制限で利用できなかった。単体HTMLの直接起動と、その場合の保存は未検証。外部アセットへの依存がないことは静的確認済み。

### 第2本追加時の確認結果

- 第1本のデータが追加前と同一であることを比較。ID、保存キー、選択肢の対応を維持。
- 単体HTMLを2本で再生成し、重複ID・内部リンク・外部アセットなし、JavaScript構文を確認。
- 別の確認用ローカルHTTP環境で、2本の切り替え、目次を使った後の動画切り替えと再読み込み、第1本を振り返るリンクを確認。
- 第2本の具体例4つの切り替え、未回答5問・全問正解5問の表示、両教材のメモと回答の復元を確認。
- 第1本だけの旧版JSONを読み込み、第1本の記録が復元され、第2本の既存メモが維持されることを確認。
- 確認用の入力を空に戻した。ブラウザのエラーログなし、1280px幅で本文の横方向のはみ出しなし。第2本冒頭のプレビューを `教材プレビュー_02.jpg` に保存。
- 検証はローカルHTTP経由。ファイルを直接開いた場合の保存については、引き続きブラウザに依存する。
